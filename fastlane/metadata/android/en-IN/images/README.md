# Store images for `fastlane supply`

`upload_to_play_store` reads image assets from these subfolders (they are not
committed as binaries here — they are generated by `npm run icons` into
`docs/play/assets/`, per `docs/play/listing.md` §3). Populate them right before an
upload:

```bash
mkdir -p icon featureGraphic phoneScreenshots
cp ../../../../../docs/play/assets/play-icon-512.png            icon/
cp ../../../../../docs/play/assets/feature-graphic-1024x500.png featureGraphic/
cp ../../../../../docs/play/assets/screenshot-*.png             phoneScreenshots/
```

Expected, per the listing pack:

| Folder             | Asset                          | Requirement            |
| ------------------ | ------------------------------ | ---------------------- |
| `icon/`            | `play-icon-512.png`            | 512×512 PNG, no alpha  |
| `featureGraphic/`  | `feature-graphic-1024x500.png` | 1024×500 PNG           |
| `phoneScreenshots/`| `screenshot-*.png`             | 2–8, min 320px side    |

The `fastlane metadata` lane skips images by default; pass `images:true` once the
folders above are populated.
